Privacy Policy: atc5.builds posting tool

Last updated: November 18, 2026

This tool is a private, single-account scheduler. It publishes short videos that its owner created (code-drawn math, physics and AI simulations) to the owner's own TikTok account, and reads that account's video statistics. It has no other users.

What data is accessed

  • Basic account info (user.info.basic): display name and open ID, used only to confirm which account is connected.
  • Posting (video.publish): uploads the owner's own videos with their captions.
  • Video list (video.list): view, like, comment and share counts of the owner's own videos, used to decide which formats to make next.

Storage and sharing

Access and refresh tokens are stored encrypted as GitHub Actions secrets and in a private file on the owner's computer. Video statistics are kept in local files on that computer. No data is sold, shared with third parties, or used for advertising. No data about other TikTok users is collected.

Revoking access

The account holder can disconnect the tool at any time in TikTok: Settings and privacy → Security and permissions → Apps and services permissions. Disconnecting stops all posting immediately; the stored tokens are then deleted.
