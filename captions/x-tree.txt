This Christmas tree is 103 lines of Python. 🎄 The code on screen is the code drawing it.

Every character is a point in 3D space. The program spins all of them, flattens them onto a grid of text, and keeps whichever point is nearest in each cell. That is the whole trick.

What each part is:
• Needles: 6,000 points in a cone, in 9 whorls. Tips get a light character (*), the inside gets a dense one (#)
• Tinsel: one helix that winds 4 times round the cone
• Lights: 110 points on the branch tips, each blinking on its own clock
• Presents: 6 boxes on a golden-angle spiral, with a ribbon wherever a point is near the middle of a face
• The far side of the tree is drawn darker, which is why it reads as 3D

It only needs NumPy and runs in a normal terminal:
samuelclauser54-alt.github.io/evolve-lab/tree.py

The music is the old Ukrainian carol Shchedryk (1916), the tune behind Carol of the Bells, also generated by code.
